# CyberSec-Agent-Assistant

这是一个基于 LangGraph 实现的轻量级网络安全 AI Agent 原型。

它旨在演示 AI Agent 在网络安全辅助分析场景中的核心能力，包括：
- 任务理解
- 工具调用
- 知识检索
- 告警研判
- 报告生成

本项目运行于本地模拟环境，不执行任何真实的扫描或攻击行为，主要用于学术研究和能力验证。

## 核心技术
- **LangGraph**: 用于构建可组合、有状态的 AI 应用。
- **Python**: 主要编程语言。

## 主要特点
- **基于图的工作流**: 通过状态图 (StateGraph) 明确编排 Agent 的分析流程。
- **模拟安全工具**: 包含 CVE 查询、日志分析等模拟工具。
- **本地知识库**: 为 Agent 提供分析所需的背景知识。
- **审计日志**: 记录所有工具调用，确保可追溯性。

详细的演示和源代码请参考 `examples/cybersec_agent_assistant/` 目录。
